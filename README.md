# 朋友圈生产

在浏览器中编辑朋友圈详情页，切换四张参考图的界面样式，并导出高清 PNG。

## 本地运行

需要 Node.js 22.12 或更新版本，以及 pnpm。项目使用的 pnpm 版本记录在 `package.json`，依赖安装沿用本机的包管理器配置。

```sh
pnpm install --frozen-lockfile
pnpm dev
```

打开终端显示的本地地址。项目没有独立后端，内容、图片和草稿由浏览器本地处理；草稿保存在当前浏览器的 IndexedDB 中。

## 使用

- 在“动态内容”中编辑头像、昵称、正文、链接卡片、发布时间和附加图标。
- 在“点赞与评论”中调整点赞头像及顺序，添加、删除或编辑评论与回复。
- 在“画面设置”中调整状态栏、底部区域和字体，也可上传裁好的状态栏图片或自己的字体文件。
- 选择参考样式及导出尺寸，点击“导出高清 PNG”。默认按对应参考图的原始像素输出，也可选择两倍尺寸。内容超过手机画幅时，可切换为“随内容增高”。

四套样式的参考尺寸及排版参数以 [src/domain.ts](src/domain.ts) 为准。参考图 3 的系统来源尚未确认，苹果实机样式等待明确的截图后再校准。

内置中文字体是经过精简的 Noto Sans SC，许可见 [OFL.txt](src/assets/fonts/OFL.txt)。不同手机的系统字体、通知图标和微信版本可能不同；可通过字体微调、上传字体和状态栏图片进行校准。示例头像及链接封面从项目参考图中截取，可在编辑器中替换。

## 验证

```sh
pnpm test
pnpm build
pnpm test:e2e
```

端到端测试默认在 Windows 使用 Microsoft Edge；其他系统使用 Playwright 的 Chromium。测试覆盖真实 PNG 下载、四套参考尺寸、预览与成图一致性、长图、编辑及本地草稿恢复。测试需要本机可用的对应浏览器。

如需根据原始参考图重新生成示例素材，可运行 `scripts/prepare-assets.py`；该可选脚本需要 Python 和 Pillow。指定 `--font-source` 可以同时从本地 Noto Sans SC 变量字体重新生成字体子集，需要额外安装 fontTools 与 Brotli。原始参考图不包含在仓库中。
